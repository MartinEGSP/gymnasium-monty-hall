# Monty Hall Problem – Interactive Game & Simulation

A high school programming project developed using Processing (Java).

## About the project

This application demonstrates the Monty Hall probability problem through an interactive game and a numerical simulation.

### Interactive game
- Choose one of three doors.
- One door hides a car, while the other two hide goats.
- After a losing door is revealed, decide whether to switch doors.
- Track wins and losses across multiple rounds.

### Probability simulation
- Choose how many games to simulate.
- Compare the strategies of switching and staying.
- Observe the expected winning probabilities:
  - Switching: approximately 66.7%
  - Staying: approximately 33.3%

## Technologies
- Processing (Java)
- 2D graphics and user interaction
- Randomized probability simulation

Originally developed during high school as a programming and probability project.
